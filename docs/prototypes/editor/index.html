Prototype guide

What this study demonstrates

A canvas-led creative workbench, informed by Form Atlas’s d35 workbench, d39 contextual inspector and a52 labelled rail. This is a proposed design, not an approved native implementation.

Try these interactions

  • Choose Highlight, Pixelate or Redact, then drag a region. “Add example region” provides a keyboard alternative.
  • Select an existing mark to change its properties. “Next” settings stay separate from “Selected” settings.
  • Drag the block-size slider to see real pixelation. One completed adjustment makes one undo step.
  • Cancel a colour preview. Press Escape during a held drawing gesture. Cancel tool preserves completed marks.
  • Copy image, then Close screenshot. Copy does not remove the unsaved warning.
  • Use Save failure to inspect recovery. Session origin shows the return to saved-session review.

Prototype boundaries

Capture, Save and Copy are simulations. No desktop pixels, files, permissions or clipboard are accessed. The canvas draws synthetic content. Highlight, pixelation and opaque redaction previews work here, but this browser renderer is not the production Rust compositor.

Other annotation tools, resizing, production async races, full native session state and automatic source tracking are outside this study. Browser keyboard/focus checks do not establish macOS VoiceOver or native selector support. Pixelation is not guaranteed concealment; the original is retained.
